## Tests

On écrit les tests sous forme:

```javascript
pm.test("Check if the response status code is 200", function () { 
    pm.expect(pm.response.code).to.equal(200); 
});
//...
    pm.expect(res).to.have.all.keys("name", "birthDate"); // clefs obligatoire sans autres clefs additionnels
    pm.expect(res).to.include.keys('surname') // clefs possibles
    
//...
```

- Accès au Json : `let res = response.json()`
- Accès à une variable d'environnement: ``
- Vider une variable: `pm.collectionVariables.unset("nomVariable");`

### Null

- vérifier que null `pm.expect(champ).to.eql(null);`

### Nombres

- est un nombre : `pm.expect(pm.response.json()).to.be.a("number");`
- > 0 `pm.expect(pm.response.json()).to.be.above(0);`
- >= 0 `pm.expect(pm.response.json()).to.be.at.least(0);`

### Date

### Boolean
