---
title: NVM commandes
---

- `nvm version` RTFM
- `nvm list available` liste toutes les versions dispos
- `nvm install 18.16.0` installer une version spécifique
- `nvm install --lts` installer la detnière lts
- `nvm list` liste les versions installées
- `nvm use <version>` utiliser la version
- `nvm current` ou `node -v` connaitre la version actuellement utilisée
