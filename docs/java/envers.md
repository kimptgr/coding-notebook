---
title: l'audit avec Envers
---

Envers est une extension de Hibernate ORM qui permet d'ajouter des versionnements pour les entités.

- `org.hibernate.orm:hibernate-envers` dans gradle.properties
- Annoter les entités ou les champs avec `@Audited`
- Plusieurs tables sont crées pour les entités : 
    - entity_aud qui contient une clef étrangère menant à revinfo, revtype (0: ajout, 1: modif, 2 delete), 
    - table revinfo 

```sql
CREATE TABLE public.revinfo (
                                rev  BIGINT GENERATED BY DEFAULT AS IDENTITY NOT NULL,
                                revtstmp int8 NULL,
                                username varchar(255) NULL,
                                CONSTRAINT revinfo_pk PRIMARY KEY (rev)
);
create sequence revinfo_seq start with 1 increment by 50;
```

Les annotations: 
- `@Audited` active l'audit d'une entité ou d'une table 
- `@Audited( withModifiedFlag = true )` ajoute un flag pour la modification sous forme de booléen (ex: name_MOD)
- `@Audited( withModifiedFlag = false )` valeur par défaut pas de flag
- `@Audited(targetAuditMode = RelationTargetAuditMode.NOT_AUDITED)` pour stocker une relation vers une entité non auditée, envers stock project_id mais pas de table project_aud
- `@AuditTable("nom_de_ma_table_d_audit")` nom de la table auditée par défaut suffixe "_aud"
- `@NotAudited` exclut le champ de l'audit
