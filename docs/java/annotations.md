## Annotations principales :

- `@Component` : annotation générique
- `@RestController` : couche API REST
- `@Service` : couche métier
- `@Repository` : accès aux données

## Annotations lombock :

Lombok permet de réduire le **code répétitif (boilerplate)** en Java.
Le code est généré automatiquement à la compilation.

- `@Getter` / `@Setter`
- `@NoArgsConstructor`
- `@AllArgsConstructor`
- `@EqualsAndHashCode`
- `@ToString`
- `@Data`
- `@Entity`
- `@Table`
- `@Id`
- `@GeneratedValue`
- `@Column`
- `@Transactional`
- `@OneToOne`
- `@OneToMany`
- `@ManyToOne`
- `@ManyToMany`
- `@RestController`
- `@RequestMapping`
- `@GetMapping`
- `@PostMapping`
- `@RequestBody`
- `@Valid`
- `@PostMapping`
- `@OpenAPIDefinition`
- `@Tag`
- `@Operation`
