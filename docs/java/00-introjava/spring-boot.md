Spring est composé de plusieurs modules :

- Spring Core : IoC et injection de dépendances
- Spring Web : API REST
- Spring Data : accès aux données
- Spring Security : sécurité
- Spring Boot : configuration simplifiée

Spring Boot simplifie le développement grâce à :

- L’auto-configuration
- Les **starters**
- Un serveur embarqué (Tomcat)
- Une application packagée en JAR
- Une approche orientée microservices

L’IoC est un **design pattern** permettant :

- Un couplage faible entre les classes
- Une meilleure testabilité
- Une gestion centralisée du cycle de vie
- Une maintenance facilitée

Le contrôle est assuré par un conteneur externe.

Spring fournit un conteneur léger nommé :

- **ApplicationContext**

Il est responsable de :

- La création des beans
- Leur cycle de vie
- L’injection des dépendances
