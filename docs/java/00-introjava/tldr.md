---
title: TLDR Intro Spring
sidebar_position: 5
---

- Une API REST expose des ressources via HTTP
- Spring est un framework modulaire et puissant
- Spring Boot facilite la configuration grâce :
  - à l’auto-configuration
  - aux starters
  - au serveur embarqué
- Spring Core repose sur l’IoC et l’injection de dépendances
- Lombok réduit fortement le code Java répétitif
