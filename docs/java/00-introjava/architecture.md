Une application Web repose sur:

- **Client**
  - Application Web (Angular, React, Vue…)
  - Application mobile (Android, iOS, React Native…)
  - Application cross-platform (Flutter…)

- **Serveur**
  - Expose une API
  - Contient la logique métier
  - Accède à la base de données

La communication se fait via le protocole **HTTP**.
