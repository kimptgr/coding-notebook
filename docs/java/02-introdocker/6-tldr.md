## TL;DR

Docker permet de créer des environnements de développement **reproductibles, portables et légers** en utilisant des **conteneurs**.  
Il repose sur des **images Docker**, stockées dans des **registries** comme Docker Hub, et exécutées sous forme de conteneurs via le Docker Daemon.

Docker est largement utilisé en **DevOps**, en **intégration continue**, pour les **tests rapides** et les **déploiements automatisés**.  
Il facilite la gestion de plusieurs environnements (dev, test, prod) et simplifie l’installation de services comme **MongoDB**.

**Docker Compose** permet d’orchestrer plusieurs conteneurs à partir d’un fichier `docker-compose.yml`, décrivant les services, ports et volumes à lancer.

Docker Desktop regroupe tous les outils nécessaires pour travailler avec Docker sur tous les systèmes d’exploitation.
